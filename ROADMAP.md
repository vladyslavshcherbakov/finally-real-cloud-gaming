# Roadmap

1. Open a random autumn scene from several photos on each visit.
   - Which photos? The user provides them, or approves freely licensed ones.
2. Show finer depth detail: lamp posts, people, railings and sculptures stop the fog.
   - Should the depth map combine the reference map from the user with the model's metric scale? The user provides the reference map as a file.
3. Run on browsers without WebGPU.
   - Is a WebGL2 version with one solver wanted? The user answers.
